# TypoBot3000 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Slack bot that receives typo reports via @-mention and autonomously creates tested PRs in client-apps using claude-code-action.

**Architecture:** Python Slack Bolt app (socket mode) deployed on Railway receives @-mentions, triggers a GitHub Actions workflow_dispatch on client-apps, which runs claude-code-action to find/test/fix the typo and open a PR. The GHA workflow posts results back to the Slack thread directly.

**Tech Stack:** Python 3.12, slack-bolt, httpx, vitest (client-apps tests), GitHub Actions, claude-code-action@v1, Railway

```python
# github_dispatch.py
import httpx


def trigger_workflow(
    *,
    owner: str,
    repo: str,
    token: str,
    typo_description: str,
    slack_channel: str,
    slack_thread_ts: str,
) -> None:
    url = f"https://api.github.com/repos/{owner}/{repo}/actions/workflows/typobot.yml/dispatches"
    response = httpx.post(
        url,
        headers={
            "Authorization": f"Bearer {token}",
            "Accept": "application/vnd.github+json",
            "X-GitHub-Api-Version": "2022-11-28",
        },
        json={
            "ref": "main",
            "inputs": {
                "typo_description": typo_description,
                "slack_channel": slack_channel,
                "slack_thread_ts": slack_thread_ts,
            },
        },
    )
    response.raise_for_status()
```

- [ ] **Step 4: Implement `app.py`**

```python
# app.py
import os
import re

from slack_bolt import App
from slack_bolt.adapter.socket_mode import SocketModeHandler

from github_dispatch import trigger_workflow

app = App(token=os.environ.get("SLACK_BOT_TOKEN"))

GITHUB_PAT = os.environ.get("GITHUB_PAT", "")
GITHUB_REPO_OWNER = os.environ.get("GITHUB_REPO_OWNER", "")
GITHUB_REPO_NAME = os.environ.get("GITHUB_REPO_NAME", "client-apps")


def strip_mention(text: str) -> str:
    return re.sub(r"<@[A-Z0-9]+>\s*", "", text).strip()


@app.event("app_mention")
def handle_mention(event, say):
    channel = event["channel"]
    thread_ts = event["ts"]
    raw_text = event["text"]

    say(
        text="On it -- I'll post the PR here when it's ready.",
        thread_ts=thread_ts,
    )

    typo_description = strip_mention(raw_text)

    trigger_workflow(
        owner=GITHUB_REPO_OWNER,
        repo=GITHUB_REPO_NAME,
        token=GITHUB_PAT,
        typo_description=typo_description,
        slack_channel=channel,
        slack_thread_ts=thread_ts,
    )


if __name__ == "__main__":
    handler = SocketModeHandler(app, os.environ["SLACK_APP_TOKEN"])
    handler.start()
```

- [ ] **Step 1: Create the workflow file**

```yaml
# /Users/benji/work/client-apps/1/.github/workflows/typobot.yml
name: TypoBot3000

on:
  workflow_dispatch:
    inputs:
      typo_description:
        description: "User's typo report from Slack"
        required: true
        type: string
      slack_channel:
        description: "Slack channel ID for reply"
        required: true
        type: string
      slack_thread_ts:
        description: "Slack thread timestamp for reply"
        required: true
        type: string

jobs:
  fix-typo:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      id-token: write

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Fix typo with Claude
        id: claude
        uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: |
            A user reported the following typo:

            ${{ github.event.inputs.typo_description }}

            Your task:
            1. Find the file containing the incorrect text described above.
            2. Write a test that asserts the CORRECT text is present. Use vitest (the project's test framework). Place the test co-located with the source file, following existing conventions.
            3. Run the test and confirm it FAILS (because the typo is still there).
            4. Fix the typo in the source file.
            5. Run the test again and confirm it PASSES.
            6. Create a pull request with the title "fix: typo - [brief description]" and a body explaining what was fixed and that this was reported via TypoBot3000.

      - name: Notify Slack on success
        if: success()
        env:
          SLACK_BOT_TOKEN: ${{ secrets.SLACK_BOT_TOKEN }}
        run: |
          PR_URL=$(gh pr list --head "${{ steps.claude.outputs.branch_name }}" --json url --jq '.[0].url')
          curl -s -X POST https://slack.com/api/chat.postMessage \
            -H "Authorization: Bearer $SLACK_BOT_TOKEN" \
            -H "Content-Type: application/json" \
            -d "{
              \"channel\": \"${{ github.event.inputs.slack_channel }}\",
              \"thread_ts\": \"${{ github.event.inputs.slack_thread_ts }}\",
              \"text\": \"PR ready: ${PR_URL}\"
            }"

      - name: Notify Slack on failure
        if: failure()
        env:
          SLACK_BOT_TOKEN: ${{ secrets.SLACK_BOT_TOKEN }}
        run: |
          curl -s -X POST https://slack.com/api/chat.postMessage \
            -H "Authorization: Bearer $SLACK_BOT_TOKEN" \
            -H "Content-Type: application/json" \
            -d "{
              \"channel\": \"${{ github.event.inputs.slack_channel }}\",
              \"thread_ts\": \"${{ github.event.inputs.slack_thread_ts }}\",
              \"text\": \"I couldn't fix this one. Check the workflow run: ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}\"
            }"
```
